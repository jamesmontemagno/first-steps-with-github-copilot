01 · Lab overview

One app. The whole development loop.

The GitHub Copilot app is a desktop workspace built on Copilot CLI. It brings parallel agent sessions, integrated browsing, GitHub issues and pull requests, automations, and shared canvases into one focused experience.

⌁

Work in parallel

Each session gets an isolated worktree, so agents can tackle multiple tasks without colliding.

◫

Stay in the flow

Build, preview, inspect diffs, manage issues, and review pull requests without context switching.

✦

Direct the work

Choose Interactive or Autopilot mode, then steer agents with prompts and visual tools.

◎
What you’ll build

A colorful, single-file space quiz. You’ll polish it in the integrated browser, publish it to GitHub, create a backlog, ship an issue through review, and explore automation and Canvas extensions.

Before you begin

Prerequisites

Works on macOS, Windows & Linux

Organization account? Copilot Business and Enterprise administrators must enable the Copilot CLI policy before the app will work.

03 · Guided app tour

Build it. Ship it. Improve it.

Take a standalone space quiz from an empty folder to a reviewed pull request, then put recurring work on autopilot and explore a visual Canvas workflow.

CreateBuildPublishReviewAutomate
01
Create

Create the Space Quiz workspace

Start a fresh local session with settings that keep you in control.

  1. Open the Copilot app and confirm you’re signed in.
  2. Select the New tab.
  3. Choose Local folder or repository, then create or select an empty folder named space-quiz.
  4. Set the session mode to Interactive.
  5. Choose GPT-5.3-Codex if available, or Auto as the fallback.
  6. Confirm the workspace is the local space-quiz folder.
02
Build & polish

Build in the integrated browser

Send one detailed prompt and follow the agent as it creates index.html.

✦ Send this prompt
Create a space exploration quiz with 10 questions, a progress bar, score counter, and colorful animated feedback (green for correct, red shake for wrong). Show a results screen with emoji reaction at the end. Center in a narrow column. Single index.html, no server/dependencies. Polished, sans-serif, 14–16px body, prefers-color-scheme. Open in the integrated browser.

Play a few questions. Confirm the progress bar, score, correct state, and incorrect shake all work.

Inspect the generated code

Collapse the left sidebar and right-side browser panel, review index.html in the expanded code area, then restore both panels.

Polish with the element picker

  1. Choose the element picker in the browser toolbar.
  2. Select the quiz heading or answer area.
  3. Send the prompt below and watch the browser refresh.
✦ Visual refinement
Make the selected element feel more like a mission-control display. Keep it accessible and preserve the existing light and dark themes.
Optional follow-up ideas +
  • Add a subtle star-field background that respects prefers-reduced-motion.
  • Make the results screen more celebratory when the score is 8 or higher.
  • Improve keyboard focus states and verify the quiz without a mouse.
03
Publish

Publish the local project

Turn the experiment into a public GitHub repository.

✦ Send this prompt
Initialize this folder as a Git repository, create an initial commit, and create a new public GitHub repository named space-quiz in my account. Push the current branch and set it as the default branch. Refresh the project within this app so the GitHub project is linked.
Review before approvingThe agent will ask for confirmation before it creates a repository or pushes code. Review the action, approve it, then confirm index.html appears on GitHub.
04
Issues & sessions

Build a backlog in My work

Ask the agent to turn its own product ideas into focused work items.

✦ Create three issues
Review the space quiz and suggest three focused feature ideas that could each be completed in a short session. Create a separate GitHub issue for each idea with a clear title, user-focused description, and acceptance criteria. Do not implement them yet.

Open My work, compare the scope and acceptance criteria of the three new issues, and choose one to implement.

Implement an issue in an isolated worktree

  1. Open your chosen issue in My work and select New session.
  2. Choose a new worktree when prompted.
  3. Use Interactive mode and GPT-5.3-Codex, or Auto as the fallback.
  4. Send the implementation prompt below.
  5. Review the diff and verify the feature in the integrated browser.
✦ Implement the issue
Implement this issue completely. Keep the single-file, dependency-free design, test the behavior in the integrated browser, and summarize the changes when finished.
05
Review

Complete the Copilot review loop

  1. Select Create PR in the session toolbar.
  2. Review the generated title and description, then create the pull request.
  3. Open it on GitHub and request Copilot from the Reviewers menu.
  4. Read every comment in the Files changed tab.
  5. For up to two actionable comments, use the Copilot Fix action in the app.
  6. Review each change, retest it, reply with what changed, and resolve the conversation.

If Copilot leaves fewer than two actionable comments, fix all it provides—don’t manufacture unnecessary changes.

06
Automate

Schedule weekly issue triage

  1. Open Automations and choose the template for a new weekly automation.
  2. Enter the prompt below.
  3. Set session mode and model to Autopilot and Auto.
  4. Select the space-quiz project.
  5. Open the Create dropdown and choose Create and run.
⚡ Weekly automation
Reviews the latest GitHub issues created and are open in the last week, and provide a summary table ranked by severity and priority
07
Canvas

Kick off work from a Kanban Canvas

A Canvas is a shared, bidirectional surface where you and an agent can read and update the same plan, board, checklist, or dashboard.

  1. Browse the Canvas extensions gallery.
  2. Open the Repository Issues Kanban extension.
  3. Select Install in GitHub Copilot app and approve it.
  4. In Customize → Canvas, confirm the extension is installed.
  5. Select New session for the Canvas and choose space-quiz.
  6. Explore the board, then drag an issue card into the active-work column.
  7. Open the automatically generated session and confirm the issue context is ready.
